# libapps-accessibility
Use these Javascript scripts to add accessibility/improve usability in Springshare's LibGuides and LibCal. The scripts address four issues:
* automatically setting the alt text for profile and book cover images for consistency;
* indicating the current/active page for all users;
* providing a visual indication for all links that open in a new window;
* and restructuring the LibCal weekly hours page.

Scripts can be copied/pasted to the Custom JS sections of each tool's Look & Feel page and can be applied to your library's Bootstrap 3 and Bootstrap 5 instances.
